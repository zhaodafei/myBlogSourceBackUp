### CAD图形特性

CAD图形特性相关笔记
三个基本特性：  颜色、线宽、线型

#### 更改特性

```wiki
更改特性的两种方式
  1.绘图区域上方的“特性”工具条
  2.按Ctrl+1呼出特性栏（或者PR指令）
 区别：
    Ctrl+1特性栏中，有更多参数可以调整，而绘图区域上方的工具条则只有三个基本特性可以调整
    但是1.可以改变当前特性（置为当前）
    
改变对象：选择对象后，去更改特性

置为当前：无选择的情况下，直接更改特性
（特性、字体、标注、图层同理）
```

#### 关于Bylayer和Byblock

```wiki
关于Bylayer和Byblock
By意为“跟随”
  1.ByLayer中，Layer为图层
  所以为跟随图层的意思，线条处于哪一个图层，特性就会跟随图层的设置
  2.ByBlock中，Block为块
  所以为跟随块对象的意思，线条被制作为块，线条的特性会跟随块对象
```

#### 颜色

```wiki
颜色——
  ByLayer：跟随图层颜色
  ByBlock：跟随所形成块的颜色
  建议：用图层对图纸进行分类（下节课开始讲解）
              并且颜色都使用索引颜色
```

#### 线型

```wiki
线型——
  ByLayer：跟随图层线型
  ByBlock：跟随所形成块的线型
  新建的空白图纸没有自带线型，需要LT空格后，点击加载按钮，去选择需要的线型样式加载即可
  注意：线型具有比例因子，如果设置线型后，发现疏密程度不合适或者还是为实线，可以通过两种方式调整线型比例
    1. LTS指令，调整全局线型比例
    2. 选择对象后Ctrl+1，调整单独线型比例
```

#### 线宽

```wiki
线宽——
  ByLayer：跟随图层线宽
  ByBlock：跟随所形成块的线宽
       默认为0.25mm宽度，常见打印机最细为0.18mm
 从0.3mm开始具有线宽显示
       注意：如果设置线宽后，仍然为细线，可以输入LW空格，勾选线宽显示

```

#### MA特性匹配

```wiki
MA特性匹配
  也被叫做格式刷
 MA空格后，先去点击需要的特性/格式
 再去选择要修改的对象，就可以实现特性的统一
   
在MA空格并且拾取到特性/格式后，还可以输入S设置，去窗口中，取消一些特性的勾，就不会被匹配
```

### CAD图层的应用

CAD图层的应用
  ——快速入门版

#### 图层创建

```wiki
图层创建：LA图层管理器
   右键图层-管理图层操作
   右键空白位置-新建图层操作
 多选图层后，点击图标，可以批量修改图层
```

#### 图层使用

```wiki
图层使用：
  直接切换图层-为切换当前图层，新绘制的线条/粘贴内容，会默认放置到当前图层中
  选择对象后切换图层-为修改对象的归属图层
```

#### 图层功能

```wiki
图层功能：
  灯泡：开启/关闭图层（隐藏）
  锁头：解锁/锁定图层（能看不能动）
  太阳/雪花：解冻/冻结图层（看不到选不着）
```

#### 图层常用操作

```wiki
图层常用操作：
  LAYOFF：关闭图层操作，等同于隐藏图层内容，归属于该图层的内容，都会被隐藏
  LAYISO：隔离图层操作，关闭/锁定被选择对象以外的图层，只能对被隔离的图层中的对象进行操作
  LAYUISO：结束隔离，将被LAYISO隔离的对象解开
  LAYON：打开所有被关闭/隐藏的图层
  LAYLCK/LAYULK：锁定/解锁图层

  LAYCUR：将所选对象放到当前图层
  LAYMCUR：将所选对象的图层置为当前图层
  LAYMCH：将所选对象放到指定对象的图层
```

#### 图层设置的保存

```wiki
图层设置的保存
  其实等同于字体、标注、线型等等各种特性和样式
  都是要保存在样板文件（dwt）
  另存为（ctrl+shift+S），文件类型选择为.dwt
  注意：直接保存在默认路径中，除非你对CAD各种保存位置很了解
              为了方便找到，命名可以A1开头，相当于置顶了
```

#### 样板设置

```wiki
样板设置
  另存为完成后，OP空格，点击“文件”，下滑找到“样板设置”
  第三个选项“快速新建默认样板文件”，改成你保存的样板文件即可

偷懒技巧
  可以通过设计中心ctrl+2，快速调用并保存为自己的样板文件
  fei：选中后可以拖到新页作为新图层
```
