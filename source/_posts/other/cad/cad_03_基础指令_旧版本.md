### 指令01

#### 选择方式

```wiki
选择方式
1.鼠标左键点击对象进行选择
2.往右拉出实线框进行选择框选/窗口选择:只会选择到完全在框中的内容
3.往左拉出虚线框进行选择栏选/交叉选择:只要接触到框的对象都会被选择上
```

#### L直线指令

```wiki
L直线指令
PL多段线指令
ML多线指令
SPL样条曲线
(以上指令共同功能:输入C关闭，可以闭合线段头尾，形成闭合区域)

F8正交模式(按住shift键为临时开关)限制光标的编辑方向为水平/垂直的轴向
```

#### F10极轴追踪

```wiki
F10极轴追踪
 从上一个点/基点延伸出虚线，与光标进行对齐和追踪操作虚线方向可以进行设置(SE)
 增量角: 为每根虚线之间的夹角
 附加角: 单独设置的角度线条(极轴角度)

角度替代
 在指令中定点定位需要一个角度方向时，输入<角度值进行编辑方向限制
 角度符号:‘<’小于号,逗号键大写，注意关闭中文输入法，否则为书名号《
```

### 指令02

#### F11对象追踪

```wiki
F11对象追踪
 在需要定点定位的指令中，光标在捕捉标记点上停留，
 可以从该点延伸出虚线，与光标进行对齐和追踪操作
```

#### F12动态输入

```wiki
F12动态输入
 有利有弊的功能，可以灵活使用
 优点: 输入指令、命令提示实时显示在光标右下角
      TAB键可以切换输入数值的类型(增量、总长、角度等)
 缺点: 无法使用绝对坐标、用户坐标(UCS)进行定位，都是进行相对坐标进行定位。
```

#### TT临时追踪

```wiki
TT临时追踪指令
 弥补F11对象追踪只能单方向追踪的缺陷，在没有标记点的位置临时放置追踪点，可以进行多点延伸定位。
```

#### TK连续追踪指令

```wiki
TK连续追踪指令
 在指令中需要定点定位时输入(否则显示为未知指令)
 光标点击第一个点出发，控制方向(切换方向需要靠近点)
 输入追踪距离，到达目标位置后，空格或者回车结束追踪，确定该点位置。
```

#### TR修剪指令

```wiki
TR修剪指令
 原理:线条与线条的接触位置作为边界，光标点击即可修剪掉
 1.直接修剪: 输入指令后空格两下，直接点击进行修剪
 2.边界修剪: 先选择一根或者多根线条作为剪切边，再开始修剪
```

#### EX延伸指令

```wiki
TR修剪指令和EX延伸指令
 原理一致，操作也一致，并且可以通过按住shift键互相切换功能(适用于修图改图)
 注:也可以使用F圆角指令进行修剪(R=0或按住shift键选边)
```

#### MI镜像指令

```wiki
镜像指令MI
 选择要镜像的对象，指定镜像线(选择两点连线)
 最后是否需要删除源对象Y/N(默认否)
```

### 指令03

#### M移动指令

```wiki
移动指令M(操作和CO复制指令一致)
 选择对象，指定基点(光标拖拽移动点)
 放置到目标位置即可
```

#### C0/CP复制指令

```wiki
C0/CP复制指令
选择要移动的对象，指定基点(移动点)放置到目标位置即可
注:高版本CAD的复制指令新增A阵列功能
```

#### S拉伸指令

```wiki
拉伸指令S 
 选择对象必须使用虚线框进行交叉选择
 1.拉伸位置:和虚线框接触的线条，产生形变
 2.位移对象:被选择上，但没有接触到虚线，只位移指定基点(光标拖拽拉伸的点)拉伸到目标位置即可
```

#### AL对齐指令

```wiki
对齐指令AL
 选择对象，指定对齐点(平面两次，三维三次)
 对齐点: 先选择源点，再点击要对齐的位置点
 是否对齐缩放: 指对象是否按照所选对齐点位置进行等比缩放
```

### 指令04

#### RO旋转指令

```wiki
RO旋转指令
 选择对象，指定基点(旋转中心点)
 C复制:旋转完成后，原位置对象保留输入角度:遵循“逆正顺负”规律
 R参照:重新指定参照角度
   1.重新指定光标拖拽位置
   2.为拾取的线段重新指定角度(与x轴夹角)
```

#### O偏移指令

```wiki
O偏移指令
 先指定偏移距离，选择对象，光标控制方向点击确定即可
 T通过: 由光标确定偏移到的位置，点哪到哪
 E删除: 开启后，偏移完成会自动删除源对象
 L图层: 更改偏移出的线条所在图层
   C当前:偏移到当前图层中
   S源: 和源对象在同一个图层中
   
指令小技巧:命令行中输入数值时，出现“指定”二字，
则可以直接在图纸中拾取点击两点拾取一段距离(代替手动输入数值)
```

### 指令05

#### REG面域指令

```wiki
REG面域指令
 将线条形成的闭合区域转化为面域
 注:必须要完全闭合的对象，缺口、突出都将面域失败
```

#### 布尔运算

```wiki
布尔运算
 般用于三维建模实体编辑，也有少数情况被应用于二维绘图的修剪操
 
 作包括四种编辑方式
 IN交集: 选择多个对象，保留对象重叠部分模型
 UNI并集: 选择多个对象，将多个对象合并为一个模型
 SU差集(A-B和B-A两种):
   选择两组对象，第一组被第二组切除重叠部分。
   (用于三维建模中的材料切除)
```

### 指令06

#### C圆绘制指令

```wiki
圆绘制指令C
 指定圆心点，输入半径，或者D输入直径
 3P三点画圆/2P两点画圆
 T切点切点半径画圆
 三相切画圆
```

#### A圆弧绘制指令

```wiki
圆弧绘制指令A

 三点画圆弧: 依次点击三个点，绘制出穿过三点的圆弧
 条件画圆弧: 根据已知条件，在命令行选择相应的功能进行绘制
   起点、第二点、圆心C、端点E
   半径R、角度A、方向D(相切)、长度L(弦长)
 注:圆弧大部分画法要按逆时针绘制。(方向、三点例外)
```

### 指令07

#### CAD的坐标定位

```wiki
CAD的坐标定位
 绝对坐标: 以世界坐标、用户坐标的0,0作为原点，进行定位
  没有开启F12动态输入的状态下，直接输入坐标值即可
  
 相对坐标: 以上一个点/FR0基点作为原点，进行定位
  输入@坐标值，若开启了F12动态输入则可以不@
```

#### CAD的坐标分类

```wiki
CAD的坐标分类
 直角坐标:x，y以横纵两个方向数值构成(二维)
         x,y,z笛卡尔坐标
         
 极轴坐标: 长度〈角度 以长度值和方向角度构成(二维)
         长度〈在xy面与x轴的角度<Z轴中的高度(柱坐标)
         长度〈在xy面与x轴的角度〈与xy面的角度(球坐标)
```

#### F圆角指令

```wiki
F圆角指令:
 通过R设置半径，选择两条边进行圆角操作
 T修剪模式: 默认开启，“长修短补”，输入N关闭
 M多个: 可以连续进行圆角操作
 P多段线: 选择多段线对象，自动圆角
```

### 指令08

#### 夹点编辑法

```wiki
夹点编辑法
 夹点: 选择图形后出现的蓝色方块点(数量太多时会自动隐藏)
 使用方法:点击夹点(变成红色)，即可进入夹点编辑的拉伸功能，空格键可以切换夹点编辑法的功能
 功能: 1.拉伸
      2.位移(MOVE)
      3.旋转
      4.比例缩放
      5.镜像
(五个功能循环)
C复制:进入多重编辑模式
R参照:和原指令参照用法一致
B基点:重新指定基点位置
ESC键退出夹点，U/ctrl+z撤回
```

#### REC矩形指令

```wiki
REC矩形指令
 指定第一个角点，D尺寸输入长度和宽度(先横后纵)
 最后指定矩形的朝向
 D尺寸: 输入长度和宽度，绘制矩形
 A面积: 输入面积和一边长度，绘制矩形
 R旋转: 为即将绘制的矩形设定角度
在矩形第一个角点前，可以设置矩形的形状参数C倒角、F圆角、T厚度、E标高、W宽度
```

#### CHA倒角

```wiki
CHA倒角
 设定倒角参数后，依次选择两条边进行倒角操作
 D距离: 设定两边长度，进行倒角
 A角度: 设定一边长度和角度，进行倒角
 T修剪模式: 默认开启，“长修短补”，输入N关闭
 P多段线: 选择多段线，自动进行倒角
 M多个: 开启后可以进行连续倒角操作
```
