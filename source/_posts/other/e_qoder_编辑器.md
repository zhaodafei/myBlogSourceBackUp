### 基础配置

```wiki
#恢复原始配置
在这个目录 C:\Users\fei\AppData\Roaming\Qoder\User 中有个文件 settings.json,删除即可

#设置编辑器颜色
头像 / 编辑器设置 / 主题(搜索) / 常用设置( 选择: Qoder Light )

#设置编辑器字体
头像 / 编辑器设置 / 字体(搜索) / 文本编辑器/字体 / 字体大小(16) 
## webstorm 中
File / Setting / Editor / Font / size(16)

#设置单击打开新页签打开文件
通过设置界面操作（最直观）
打开设置，或者点击左下角齿轮图标，选择“设置”。
在搜索框里输入 preview。
找到 Workbench(工作台) › Editor: Enable Preview 这个选项，取消勾选它就可以了

#设置点击文件后左侧目录停止自动展开定位( 这个不要修改, 没有和idea中alt+F1配合键 )
通过设置界面操作（最直观）
打开设置，或者点击左下角齿轮图标，选择“设置”。
在搜索框里输入 autoReveal
找到[ 功能/资源管理器/Auto Reveal ] 把这个选项改为false
```

### editor-新建会话

在日常开发中，建议采用 **“单任务单会话 + 适时压缩”** 的策略：

1. 为一个主要的功能模块开启一个会话。
2. 当会话长度达到一定阈值（或者你感觉到变慢时），点击一次 **「压缩当前会话」**。
3. 当该功能模块彻底完成后，不要继续在这个会话里做下一个功能，直接 **「新建会话」** 开始下一个任务。

这样既能保证 AI 对当前任务的深度理解，又能有效控制成本并保持思维的清晰度。

| 你的情况                                 | 推荐操作     | 理由                                           |
| ---------------------------------------- | ------------ | ---------------------------------------------- |
| 正在做同一个大功能，只是聊太久了         | 压缩当前会话 | 保持上下文连贯，避免重新解释背景。             |
| 刚做完一个功能，要做下一个完全不同的功能 | 新建会话     | 避免旧逻辑干扰新任务，防止 AI 混淆。           |
| AI 开始胡言乱语，完全听不懂人话了        | 新建会话     | “重启”往往比“修补”更有效，彻底清除错误思维链。 |
| 担心 Credits 不够用了                    | 压缩当前会话 | 在不中断工作流的前提下最大化节省 Token。       |
| 只是想问个简单的语法问题                 | 新建会话     | 杀鸡焉用牛刀，干净利落。                       |
